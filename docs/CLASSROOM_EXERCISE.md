# Classroom Exercise (Simple)

## Goal
Run the lab, test a few files, and explain one mistake the system makes.

## Steps
1. Train the model on `data/dataset_classroom.csv`.
2. Run the app.
3. Upload at least four files from `sample_inputs/`:
   - one obvious phishing sample
   - one legitimate sample
   - one `.eml` sample
   - one borderline sample
4. Fill in the table below.

| File | Predicted label | Risk score | Two cues you saw | Was the result correct? |
|---|---|---|---|---|



## Deliverable
A short answer of 150-250 words plus the completed table.
